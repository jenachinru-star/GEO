# GEO数字资产助手 - Chrome扩展

## 功能
- 一键收藏当前网页到GEO数字资产库
- 支持分类、标签、备注
- 支持自动AI总结（开启后后台自动处理）
- 右键菜单快捷收藏
- 选中文字快速收藏

## 安装方法（开发模式）

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本目录（`frontend/extension/`）
5. 扩展安装完成，浏览器工具栏会出现GEO图标

## 使用方法

### 一键收藏网页
1. 打开任意网页
2. 点击浏览器工具栏的GEO图标
3. 修改标题、分类、标签（可选）
4. 点击"收藏到数字资产库"

### 右键快捷收藏
1. 在网页空白处右键 → "收藏到GEO数字资产库"
2. 选中文字右键 → "收藏选中内容到GEO"

### API配置
- 首次使用请在弹窗底部配置API地址
- 默认地址: `http://10.16.190.100:8028/geo/api/v1`

## 文件结构
```
extension/
├── manifest.json      # 扩展配置（Manifest V3）
├── popup.html         # 弹窗界面
├── popup.js           # 弹窗逻辑
├── content.js         # 内容脚本（在页面中运行）
├── background.js      # 后台Service Worker
└── icons/             # 图标目录（需要自行添加）
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 注意事项
- 需要在GEO系统中登录后才能使用（Cookie认证）
- 如果跨域请求失败，需要在后端配置CORS允许扩展访问
- 图标文件需要自行准备或生成
