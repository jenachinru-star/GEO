## 二、任务完成详情

### 任务1：Dashboard "Top5" → 语义表现概览

**改动文件**：`frontend/src/pages/Dashboard.tsx`

**改动内容**：
1. 新增 import：`Empty`、`ArrowRightOutlined`、`useNavigate`、`geoApi`；移除不再使用的 `Table`、`Tag`
2. 新增 state：`semanticStats`（存储完整语义统计数据）、`navigate`
3. `loadData` 改为 `Promise.all` 同时调用 `dashboardApi.getDoctorStats()` 和 `geoApi.getOverview()`
4. 新增计算：`topGeo`（按 geo_rate 降序取前3）、`topAeo`（按 aeo_rate 降序取前3）
5. 替换原"GEO表现最好 Top5"和"需重点优化语义"两个表格区域为单个"语义表现概览"卡片
6. 卡片内左右两列：📈 GEO推荐率最高（前3）+ 🎯 AEO引用率最高（前3）
7. 右上角"查看全部"按钮跳转 `/data`（数据中心）
8. 空状态使用 `Empty.PRESENTED_IMAGE_SIMPLE`

**关键决策**：后端 `dashboard_service.py` 的 `top_semantics` 仅返回 GEO 率前5条（`sorted(...)[:5]`），无法从中取 AEO 前3。因此必须额外调用 `geoApi.getOverview()` 获取完整 `semantic_stats`（含所有语义），再分别排序取前3。

### 任务2：数据中心语义详情抽屉 → 各平台检测结果卡片

**改动文件**：`frontend/src/pages/DataCenter.tsx`

**改动内容**：
1. 新增 state：`expandedRaw`（当前展开原始回答的 platform_code，null 表示都不展开）
2. 新增函数：`toggleRawAnswer(platformCode)`（切换原始回答展开/收起）
3. `handleViewDetail` 中打开抽屉时重置 `expandedRaw` 为 null
4. 替换原平台检测结果展示（geo-card + Tag + raw_answer 直接展开）为新的平台卡片列表
5. 每个平台卡片包含：
   - 序号（01、02...）+ 平台名称
   - 状态标签（优先级：AEO已引用为唯一答案 > GEO已推荐排名 > 未提及），三种状态对应不同颜色和背景色
   - 分析文案（根据状态自动生成描述）
   - "查看原始回答"/"收起原始回答"按钮，点击展开 raw_answer（maxHeight 200px 滚动）
6. 空状态提示"暂无平台检测数据，请先手动刷新采集"

**状态优先级逻辑**：
- `aeo_cited === true` → 已引用为唯一答案（蓝色 #2563EB）
- `geo_mentioned === true` → 已推荐，排名第N（绿色 #10B981）
- 否则 → 未提及（红色 #EF4444）

### 任务4：合并创作中心+我的文章 → "内容中心"

**改动文件**：
- 新建：`frontend/src/pages/ContentHub.tsx`
- 修改：`frontend/src/router/index.tsx`
- 修改：`frontend/src/components/Layout.tsx`（菜单合并，见任务3）
- 删除：`frontend/src/pages/Create.tsx`、`frontend/src/pages/Content.tsx`

**ContentHub.tsx 页面结构**（从上到下）：

```
内容中心
├── 页面标题栏（标题+描述+添加文章按钮+刷新按钮）
│
├── 【创作工作台】（来自 Create.tsx）
│   ├── 语义选择卡片（下拉选择 + 选中后显示GEO率/AEO率/文章数信息条）
│   ├── 工具卡片 Row（两列）
│   │   ├── 生成文章卡片（平台选择+AI价值提示+平台规则+打开文章工具按钮）
│   │   └── 生成视频卡片（打开视频工具按钮）
│   └── GEO/AEO 文章模板卡片（选语义后显示，生成模板+一键复制）
│
└── 【文章管理】（来自 Content.tsx）
    ├── 统计卡片 Row（文章总数/已发布/实体一致）
    ├── 筛选栏（搜索标题/关联语义/状态）
    ├── 文章表格（标题/关联语义/平台/状态/实体一致性/创建时间/操作）
    └── 详情抽屉（文章信息+实体校验+文章内容+分发记录管理）
```

**State 合并策略**：
- 创作工作台 state：`semantics`、`selectedSemantic`、`selectedPlatform`、`toolConfig`、`templateData`、`templateLoading`
- 文章管理 state：`list`、`total`、`loading`、`modalVisible`、`editMode`、`editId`、`drawerVisible`、`detail`、`validateResult`、`form`、`filters`、`page`、`stats`、`distributions`、`distForm`
- `semantics` 两个组件共用，合并为一份
- Create.tsx 中的 `articles` 状态和"已记录文章"卡片被移除，由 Content.tsx 的文章管理（带分页+筛选）完全替代
- Create.tsx 的"记录文章弹窗"被 Content.tsx 的"添加/编辑弹窗"替代（支持编辑，含关联语义选择）；从创作工作台添加时预填当前 `selectedSemantic`

**路由修改**：
- `/content` 路由组件从 `Content` 改为 `ContentHub`
- `/create` 路由改为 `<Navigate to="/content" replace />` 重定向
- 移除 `Content` 和 `Create` 的 lazy import

**旧文件处理**：
- 全局搜索确认无其他文件 import Create 或 Content
- 删除 `Create.tsx` 和 `Content.tsx`
- 构建产物中不再出现 Create/Content chunk，ContentHub chunk 为 38.34 kB
