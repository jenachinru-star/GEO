## 1. 已核实的代码事实（不要凭印象，以这里为准）

### 1.1 后端关键事实

| 项 | 真实情况 |
|---|---|
| JWT验证 | `IAMService.verify_jwt(token)` 是 **@staticmethod**，返回 `Optional[Dict]`，成功时payload含 `user_id`/`username`/`role`/`exp`/`iat`，失败返回None |
| 适配器查询 | `BaseAdapter.query(question, system_prompt=None)` 返回 `QueryResult` dataclass，字段：`platform_code`/`answer`/`success`/`error`/`raw_response` |
| 适配器工厂 | 全局单例 `adapter_factory`，方法：`get_adapter(code)→Optional[BaseAdapter]`，`get_enabled_platforms()→List[str]` |
| 数据库初始化 | `init_db()` 里**显式import每个模型文件**：`from app.models import platform, question, monitor, content, knowledge, competitor, user`，然后 `Base.metadata.create_all()`。**新模型必须加到这个import行里，否则表不会创建！** |
| 模型导出 | `app/models/__init__.py` 显式import每个模型类 + `__all__`列表。新模型必须两处都加 |
| 路由导出 | `app/api/__init__.py` 显式import每个router + `__all__`列表。新router必须两处都加 |
| 路由注册 | `main.py` 从 `app.api` import router列表后 `app.include_router()` |
| API返回格式 | `{"code": 0, "message": "success", "data": ...}` |
| auth路由前缀 | `/api/auth`（注意：不是`/api/v1/auth`！） |
| 其他路由前缀 | `/api/v1/monitor`、`/api/v1/content`等 |
| CORS | `main.py` 硬编码 `allow_origins=["*"]` |
| 配置 | `config.py` 用Pydantic `BaseSettings`，从`.env`读，全局单例 `settings` |
| Pydantic模型 | `schemas/__init__.py` 单文件，用 `BaseModel` + `class Config: from_attributes = True` |
| 用户创建 | `IAMService.get_or_create_user()` 创建用户时硬编码 `role="user"` |
| 定时任务 | `main.py` 的 `scheduled_collect()` 用 `Question` 表 + `CollectorEngine.collect_one_question()`，第一阶段不动 |

### 1.2 前端关键事实

| 项 | 真实情况 |
|---|---|
| Axios baseURL | `/api/v1`（所以 `request.get('/doctor/profile')` 实际请求 `/api/v1/doctor/profile`） |
| 请求拦截器 | **没有加Authorization header**！只做了 `return config`。加JWT鉴权后必须在这里加token，否则所有API返回401 |
| 响应拦截器 | `res.code !== 0 && res.code !== undefined` 时 `message.error` 并reject；401等HTTP错误走error分支 |
| 状态管理 | Zustand，`interface AppState`，token存localStorage `geo_token`，user存 `geo_user`，`setAuth(token, user)` 同时写两处 |
| 路由 | React Router v6，lazy加载，`/sso`独立布局，其他在 `MainLayout` 下，`/` 重定向到 `/dashboard` |
| 菜单 | `Layout.tsx` 中 `menuItems` 硬编码数组，字段 `{key, icon, label}` |
| 布局风格 | Sider暗色 `#0F172A`，Header白色 `#fff`，Content背景 `#F8FAFC`，主色 `#0EA5E9` |
| Vite代理 | `/api` → `http://localhost:8000`，**无rewrite** |
| 路径别名 | `@` → `./src` |
| auth API特殊处理 | `authApi.getUserinfo` 用 `axios.get('/api/v1/auth/userinfo')` 而不是 `request.get()`，因为auth路由前缀是 `/api/auth` 不是 `/api/v1/auth`——这是现有不一致 |

## 2. 绝对不能违反的硬约束

| # | 硬约束 | 原因 |
|---|---|---|
| 1 | 后台**不做文章生成器**，只做跳转入口 | 文章工具已有现成版本 |
| 2 | 语义=患者会真实提问的**问题**，不是知识图谱 | 思维导图明确 |
| 3 | GEO=被AI**推荐进列表**；AEO=被AI**引用为唯一答案** | 定义不能混淆 |
| 4 | 语义基于Profile**自动生成**，用户只能下拉选择 | 思维导图明确 |
| 5 | 自我介绍格式全网统一（"XX市XX医院XX科XX医生"） | 防止AI降权，核心壁垒 |
| 6 | 所有业务数据按`user_id`隔离 | 多租户基本要求 |
| 7 | 除auth外所有新API必须加JWT鉴权 | 当前裸奔，必须修 |
| 8 | 第一阶段**不做**GEO/AEO检测、付费体系、创作跳转、实体校验 | 那是第二三阶段 |
| 9 | 竞品/知识库/RAG代码**保留但菜单隐藏**，不删除 | 远期可能用 |
| 10 | 数据库保持SQLite | 迁移是远期事 |
| 11 | 新API前缀用 `/api/v1/doctor` 和 `/api/v1/semantic` | 和monitor等保持一致，前端request能正确拼接 |
| 12 | 前端加JWT鉴权后，**必须同步改请求拦截器加token** | 否则全401 |

```python
"""通用依赖注入"""
from fastapi import Depends, HTTPException, Request
from app.services.iam_service import IAMService


def get_current_user_id(request: Request) -> int:
    """从JWT中提取当前用户ID。未登录或token无效返回401。"""
    auth_header = request.headers.get("Authorization", "")
    if not auth_header.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="未登录")
    token = auth_header[7:]
    payload = IAMService.verify_jwt(token)
    if not payload:
        raise HTTPException(status_code=401, detail="登录已过期")
    return payload["user_id"]
```

> 核实：`IAMService.verify_jwt` 是 `@staticmethod`，所以不需要实例化，直接 `IAMService.verify_jwt(token)` 调用。返回dict的 `user_id` 是int。

```typescript
request.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('geo_token')
```

### 任务3：后端 — 语义自动生成引擎

**文件改动**：
- 新建 `backend/app/engines/semantic_generator.py`

```python
"""语义自动生成引擎 — 基于医生Profile调用LLM生成语义问题"""
import logging
import re
from typing import List
from app.adapters import adapter_factory
from app.adapters.base import QueryResult

logger = logging.getLogger(__name__)


class SemanticGenerator:
    """基于医生Profile信息，调用LLM生成关联语义问题"""

    SYSTEM_PROMPT = """你是一个医疗健康领域的语义分析专家。
根据医生的真实执业信息，生成患者会在AI搜索中真实提问的问题。

规则：
1. 必须将医生的执业地域（省+市）、医院、科室、专长疾病进行绑定
2. 生成的问题必须是患者真实会问的，不是学术问题
3. 每个问题要具体，不能太笼统（"妇科炎症看哪个医生"优于"妇科问题"）
4. 覆盖不同提问角度：找医生、找医院、问治疗、问费用、问预防等
5. 最少生成10个，最多15个
6. 严格基于医生提供的真实信息，不得编造医院或专长

输出格式：每行一个问题，不要编号，不要解释，不要markdown。"""

    def __init__(self, platform_code: str = None):
        self.platform_code = platform_code

    def generate(self, profile: dict) -> List[str]:
        """生成语义问题列表"""
        user_prompt = f"""医生信息：
姓名：{profile.get('real_name', '')}
职称：{profile.get('title', '')}
地域：{profile.get('province', '')}{profile.get('city', '')}
医院：{profile.get('hospital', '')}
科室：{profile.get('department', '')}
专长：{profile.get('specialty', '')}

请生成患者会在AI搜索中提问的相关问题。"""

        adapter = self._get_adapter()
        if not adapter:
            logger.warning("无可用AI平台，使用模板兜底生成")
            return self._fallback_generate(profile)

        result: QueryResult = adapter.query(user_prompt, system_prompt=self.SYSTEM_PROMPT)
        if not result.success:
            logger.warning(f"语义生成LLM调用失败: {result.error}")
            return self._fallback_generate(profile)

        # 解析回答，每行一个问题
        questions = []
        for line in result.answer.split('\n'):
            line = line.strip()
            # 去掉编号前缀（1. / 1、 / (1) / 1)）
            line = re.sub(r'^[\d]+[\.、\)）]\s*', '', line)
            # 去掉markdown列表符号
            line = re.sub(r'^[-*•]\s*', '', line)
            if line and 5 < len(line) < 100:
                questions.append(line)

        # 去重（保持顺序）
        questions = list(dict.fromkeys(questions))

        # 不足10个用模板补充
        if len(questions) < 10:
            questions.extend(self._fallback_generate(profile))
            questions = list(dict.fromkeys(questions))

        return questions[:15]

    def _get_adapter(self):
        if self.platform_code:
            return adapter_factory.get_adapter(self.platform_code)
        platforms = adapter_factory.get_enabled_platforms()
        if platforms:
            return adapter_factory.get_adapter(platforms[0])
        return None

    def _fallback_generate(self, profile: dict) -> List[str]:
        """LLM不可用时的模板化兜底生成"""
        city = profile.get('city', '')
        hospital = profile.get('hospital', '')
        dept = profile.get('department', '')
        specialty_raw = profile.get('specialty', '')
        specialty = specialty_raw.split(',')[0].strip() if specialty_raw else ''
        name = profile.get('real_name', '')

        if not city or not specialty:
            return []

        templates = [
            f"{city}{specialty}看哪个医生好？",
            f"{city}{hospital}{dept}哪个医生好？",
            f"{city}{specialty}去哪治疗最好？",
            f"{city}{hospital}{specialty}怎么样？",
            f"{city}{specialty}治疗费用大概多少？",
            f"{city}{dept}专家推荐？",
            f"{city}{specialty}能治好吗？",
            f"{city}{hospital}{dept}挂号攻略？",
            f"{city}{specialty}预防方法有哪些？",
            f"{city}{specialty}最佳治疗时间？",
            f"{name}医生看{specialty}怎么样？",
            f"{city}{specialty}中医还是西医好？",
        ]
        return templates
```

> 核实：
> - `adapter_factory` 是 `app/adapters/factory.py` 第72行的全局单例
> - `adapter_factory.get_adapter(code)` 返回 `Optional[BaseAdapter]`
> - `adapter_factory.get_enabled_platforms()` 返回 `List[str]`
> - `adapter.query()` 返回 `QueryResult`，有 `.success` 和 `.answer` 字段
> - import路径：`from app.adapters import adapter_factory`

```python
"""医生Profile API"""
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from app.database import get_db
from app.deps import get_current_user_id
from app.models.doctor import DoctorProfile
from app.models.semantic import Semantic
from app.engines.semantic_generator import SemanticGenerator

router = APIRouter(prefix="/api/v1/doctor", tags=["医生Profile"])


@router.get("/profile", summary="获取当前医生Profile")

def save_profile(data: dict, db: Session = Depends(get_db), user_id: int = Depends(get_current_user_id)):
    profile = db.query(DoctorProfile).filter(DoctorProfile.user_id == user_id).first()
    is_new = not profile
    if not profile:
        profile = DoctorProfile(user_id=user_id)
        db.add(profile)

    # 只更新传入的字段
    allowed_fields = ["real_name", "title", "province", "city", "hospital",
                      "department", "specialty", "awards", "case_history"]
    for key in allowed_fields:
        if key in data:
            setattr(profile, key, data[key])

    # 自动生成统一自我介绍格式
    city = data.get("city", "") or profile.city or ""
    hospital = data.get("hospital", "") or profile.hospital or ""
    department = data.get("department", "") or profile.department or ""
    real_name = data.get("real_name", "") or profile.real_name or ""
    profile.self_intro_template = f"{city}{hospital}{department}{real_name}医生"

    db.commit()
    db.refresh(profile)

    # 首次创建时自动生成语义
    semantic_count = db.query(Semantic).filter(Semantic.user_id == user_id).count()
    generated_count = 0
    if is_new or semantic_count == 0:
        generator = SemanticGenerator()
        questions = generator.generate({
            "real_name": profile.real_name,
            "title": profile.title,
            "province": profile.province,
            "city": profile.city,
            "hospital": profile.hospital,
            "department": profile.department,
            "specialty": profile.specialty,
        })
        existing = {s.question for s in db.query(Semantic).filter(Semantic.user_id == user_id).all()}
        for q in questions:
            if q not in existing:
                db.add(Semantic(user_id=user_id, question=q, category="general"))
                generated_count += 1
        if generated_count > 0:
            db.commit()

    return {
        "code": 0,
        "message": "success",
        "data": {
            "profile": {
                "id": profile.id,
                "real_name": profile.real_name,
                "self_intro_template": profile.self_intro_template,
            },
            "semantic_generated": generated_count,
        }
    }
```

## 5. 最容易踩的10个坑

| # | 坑 | 后果 | 怎么避免 |
|---|---|---|---|
| 1 | `init_db()` 没加新模型import | 表不创建，报"no such table" | 任务2.7，必须改 `database.py` 的import行 |
| 2 | 前端请求拦截器没加token | 所有API 401 | 任务1.4，必须改 `api/index.ts` |
| 3 | `models/__init__.py` 没导出新模型 | `from app.models import DoctorProfile` 报错 | 任务2.6 |
| 4 | `api/__init__.py` 没导出新router | `main.py` import报错 | 任务4.3 |
| 5 | 新API前缀写成 `/api/doctor` | 前端request拼出 `/api/v1/api/doctor` 404 | 必须用 `/api/v1/doctor` |
| 6 | auth路由前缀是 `/api/auth` 不是 `/api/v1/auth` | 混淆后调错路径 | 新API不要学auth，学monitor用 `/api/v1/` |
| 7 | `IAMService.verify_jwt` 当实例方法调用 | 报错"missing self" | 它是 `@staticmethod`，直接 `IAMService.verify_jwt(token)` |
| 8 | 适配器query返回直接当字符串用 | 报错"has no attribute split" | 返回 `QueryResult`，用 `.answer` 取文本 |
| 9 | 删除了知识库/竞品/问答的路由 | 违反硬约束 | 只改菜单，路由保留 |
| 10 | SQLite加字段用了不支持的ALTER操作 | 报错 | SQLite只支持ADD COLUMN，User表加字段没问题；复杂变更就删库重建（数据量小） |
