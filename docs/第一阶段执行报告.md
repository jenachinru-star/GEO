### 五、遇到的问题与解决方案

表格

| 问题                                                         | 解决方案                                                  |
| ------------------------------------------------------------ | --------------------------------------------------------- |
| 系统 Python 3.14 无 fastapi 等依赖                           | 找到 `miniconda3` base 环境，已预装全部后端依赖           |
| 旧 geo_user 表缺 phone/avatar 列，SQLAlchemy 查询报 `no such column` | 用 SQLite `ALTER TABLE ADD COLUMN` 添加两列（不删旧库）   |
| 旧数据库被其他 Python 进程占用无法删除                       | 不删旧库，ALTER 加字段 + create_all 建新表并行处理        |
| 测试脚本 session 关闭后对象属性过期 (DetachedInstanceError)  | 在 `db.close()` 前将 user.id/username/role 取出到局部变量 |
