## 任务2：语义详情抽屉 → 各平台检测结果卡片

### 2.1 找到DataCenter.tsx中的详情抽屉

当前抽屉里"各平台检测结果"区域只有一个空状态。替换为平台卡片列表。

### 2.2 数据获取

点击"详情"时，调用 `geoApi.getSemanticDetail(semanticId)`，返回的 `platform_details` 数组就是各平台数据。

每个平台对象字段：
```typescript
{
  platform_code: string,     // "glm" / "minimax" / ...
  geo_mentioned: boolean,    // 是否被推荐
  geo_rank: number,          // 排名（0=未推荐）
  aeo_cited: boolean,        // 是否被引用为唯一答案
  aeo_confidence: number,    // AEO置信度
  raw_answer: string,        // AI原始回答
  detect_time: string        // 检测时间
}
```

### 2.3 平台卡片展示

每个平台一张卡片，样式参考用户给的图4：

```tsx
<div style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
  {platformDetails.length === 0 ? (
    <Empty description="暂无平台检测数据，请先手动刷新采集" image={Empty.PRESENTED_IMAGE_SIMPLE} />
  ) : (
    platformDetails.map((p: any, idx: number) => {
      const platformName = PLATFORM_NAMES[p.platform_code] || p.platform_code
      const isGeo = p.geo_mentioned
      const isAeo = p.aeo_cited
      // 状态判断：AEO引用 > GEO推荐 > 未提及
      let statusLabel, statusColor, bgColor
      if (isAeo) {
        statusLabel = '已引用为唯一答案'
        statusColor = '#2563EB'
        bgColor = '#EFF6FF'
      } else if (isGeo) {
        statusLabel = `已推荐，排名第${p.geo_rank}`
        statusColor = '#10B981'
        bgColor = '#ECFDF5'
      } else {
        statusLabel = '未提及'
        statusColor = '#EF4444'
        bgColor = '#FEF2F2'
      }
      return (
        <div key={p.platform_code} style={{
          background: bgColor, padding: '16px 18px', borderRadius: 12,
          borderLeft: `3px solid ${statusColor}`
        }}>
          <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: 8 }}>
            <div style={{ fontSize: 15, fontWeight: 600 }}>
              <span style={{ color: '#94A3B8', marginRight: 8 }}>{String(idx + 1).padStart(2, '0')}</span>
              {platformName}
            </div>
            <span style={{ fontSize: 12, fontWeight: 600, color: statusColor }}>{statusLabel}</span>
          </div>
          <div style={{ fontSize: 13, color: '#64748B', lineHeight: 1.6, marginBottom: 8 }}>
            {isAeo ? 'AI在回答中直接引用该医生为推荐答案，未列出其他竞品。' :
             isGeo ? `AI在回答中将该医生列入推荐列表，排名第${p.geo_rank}位。` :
             'AI回答中未提及该医生，给出的是通用就医建议。'}
          </div>
          {p.raw_answer && (
            <div>
              <Button type="link" size="small" style={{ padding: 0 }} onClick={() => toggleRawAnswer(p.platform_code)}>
                {expandedRaw === p.platform_code ? '收起原始回答' : '查看原始回答'}
              </Button>
              {expandedRaw === p.platform_code && (
                <div style={{
                  marginTop: 8, padding: 12, background: '#fff', borderRadius: 8,
                  fontSize: 12, color: '#475569', lineHeight: 1.7, maxHeight: 200, overflow: 'auto',
                  whiteSpace: 'pre-wrap'
                }}>
                  {p.raw_answer}
                </div>
              )}
            </div>
          )}
        </div>
      )
    })
  )}
</div>
```

### 2.4 需要的辅助数据

在useStore或DataCenter.tsx顶部定义平台名称映射：
```typescript
const PLATFORM_NAMES: Record<string, string> = {
  glm: 'GLM', minimax: 'MiniMax', deepseek: 'DeepSeek',
  doubao: '豆包', qwen: '通义千问'
}
```

### 2.5 状态管理
- `detailData`：存详情API返回的完整数据
- `expandedRaw`：当前展开原始回答的platform_code，null表示都不展开
- `detailLoading`：详情加载状态

## 任务4：合并创作中心+我的文章为"内容中心"

### 4.1 新建 ContentHub.tsx

路径：`frontend/src/pages/ContentHub.tsx`

页面结构（从上到下）：

```
内容中心
├── 页面标题栏（page-title-bar）
│   ├── 标题：内容中心
│   ├── 描述：选择语义创作内容，管理所有产出文章
│   └── 右侧：刷新按钮
│
├── 【创作工作台】geo-card
│   ├── 选择语义（下拉，必选，和Create.tsx一样）
│   ├── 选中语义后显示语义信息条（GEO率/AEO率/文章数）
│   ├── Row两列：
│   │   ├── 生成文章卡片（平台选择+AI价值提示+平台规则+打开文章工具按钮）
│   │   └── 生成视频卡片（打开视频工具按钮）
│   └── 文章模板预览（选语义后可生成模板，一键复制）—— 从Create.tsx搬过来
│
└── 【我的文章】
    ├── 统计卡片行（文章总数/已发布/实体一致）—— 从Content.tsx搬过来
    ├── 筛选栏（搜索/语义筛选/状态筛选）—— 从Content.tsx搬过来
    └── 文章表格 + 详情抽屉 —— 从Content.tsx搬过来
```

### 4.2 复用策略

**不要从零写**，把Create.tsx和Content.tsx的代码整合：
- 从Create.tsx搬：语义选择状态、工具跳转逻辑、模板预览功能、平台选择
- 从Content.tsx搬：文章列表、筛选、详情抽屉、分发记录、实体校验、统计卡片
- 两个组件的state合并到一个组件里

### 4.3 路由修改

在 `router/index.tsx` 中：
- 把 `/content` 路由的组件从 `Content` 改为 `ContentHub`
- 把 `/create` 路由改为重定向到 `/content`（或直接删除）
- lazy import 改为 `const ContentHub = lazy(() => import('@/pages/ContentHub'))`

### 4.4 菜单修改

Layout.tsx中：
- `创作中心`（/create）和 `我的文章`（/content）合并为 `内容中心`（/content）
- 图标用 `FileTextOutlined` 或 `AppstoreOutlined`

### 4.5 旧文件处理
- Create.tsx：可以删除，或保留但不引用（建议删除，避免混淆）
- Content.tsx：可以删除，或保留但不引用（建议删除）

### 4.6 关键注意
- 所有import要整理干净，不要有未使用的import
- 文章模板预览的API是 `templateApi.generateArticle(semanticId)`
- 工具跳转的URL从 `toolsApi.getConfig()` 获取
- 文章列表的API是 `articleApi.getList()`
- 分发记录的API是 `distributionApi.getList()` / `create()` / `delete()`
- 实体校验的API是 `articleApi.validate(id)`

## 坑表
