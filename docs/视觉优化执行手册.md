# 视觉优化执行手册：高级医疗专业风

> 精确可执行版。目标：从"Ant Design默认+深色侧边栏"升级为"亮色高级医疗专业风"。

## 0. 设计规范（必须严格遵守）

### 配色系统
```
主色：医疗蓝渐变 linear-gradient(135deg, #2563EB 0%, #0EA5E9 100%)
主色深：#1D4ED8
主色浅：#38BDF8

成功：#10B981  警告：#F59E0B  错误：#EF4444  紫色：#8B5CF6

页面背景：#F0F4F8（冷调浅灰蓝，比纯白高级）
卡片背景：#FFFFFF
侧边栏背景：#FFFFFF（亮色！不是深色）
侧边栏选中：linear-gradient(135deg, rgba(37,99,235,0.08), rgba(14,165,233,0.05))
侧边栏选中文字：#2563EB
侧边栏未选中文字：#64748B

文字主色：#0F172A
文字次色：#64748B
文字弱色：#94A3B8
边框：#E2E8F0
```

### 圆角与阴影
```
卡片圆角：16px
按钮圆角：10px
标签圆角：6px
卡片阴影：0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06)
卡片hover阴影：0 8px 24px rgba(0,0,0,0.08)
卡片hover位移：translateY(-2px)
```

### 字体
```
页面标题：22px / 700 / 渐变文字
卡片标题：16px / 600
正文：14px / 400
次要文字：13px / 400 / #64748B
数据数字：28-32px / 700 / 等宽感
```

### 核心原则
1. **亮色侧边栏**：白色背景，选中项用浅蓝渐变背景+蓝色文字+左侧蓝色指示条
2. **卡片统一**：所有内容区块用 `.geo-card` class，不要内联写背景/圆角/边框
3. **指标卡渐变**：数据指标卡用渐变背景（蓝/绿/紫/橙），白色文字
4. **按钮渐变**：主按钮用 `btn-primary-gradient` class
5. **留白充足**：页面padding 28px，卡片padding 24px，区块间距20px
6. **过渡动画**：所有hover有0.3s过渡

## 坑表

1. **Ant Design Menu亮色主题**：`theme="light"` 后，选中项的默认蓝色可能和我们的不一样，必须用 `.sider-menu-light .ant-menu-item-selected` 覆盖
2. **渐变文字**：必须同时写 `-webkit-background-clip: text` 和 `background-clip: text`，否则Firefox不生效
3. **毛玻璃效果**：`backdrop-filter` 在某些浏览器需要前缀，两个都写
4. **不要改功能**：视觉优化只改样式，不改任何逻辑、API调用、数据结构
5. **内联style优先级**：如果元素上有内联style写了background，class里的background会被覆盖，必须把内联的去掉
6. **指标卡渐变**：渐变背景卡上的文字必须是白色，确保对比度足够
7. **侧边栏指示条**：用 `::before` 伪元素，left值要根据menu的margin调整
