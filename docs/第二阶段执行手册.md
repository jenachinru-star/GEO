## 2. 第二阶段核心设计决策（必须理解）

### 2.1 GEO和AEO的检测逻辑

- **GEO（被推荐）**：AI回答中出现了医生姓名、医院全称、或统一自我介绍格式 → 算一次GEO推荐。提取排名（第几个被提到）。
- **AEO（被引用）**：AI回答中不仅提到了医生，还用了引用句式（"根据XX医生的观点"、"XX医生指出"）+ 给出了治疗方案/建议 → 算一次AEO引用。记录置信度。
- **GEO率** = 被推荐的平台数 / 总平台数 × 100%
- **AEO率** = 被引用的平台数 / 总平台数 × 100%

### 2.2 数据模型关键决策：question_id填semantic.id

**这是最容易出错的地方。**

`MonitorRecord.question_id` 是NOT NULL，且唯一约束包含它。医生维度的记录如果填0，所有语义的记录question_id都是0，同一天同一轮次同一平台会唯一约束冲突。

**正确做法**：医生维度采集时，`question_id` 填 `semantic.id`（语义表的主键），同时 `semantic_id` 字段也填 `semantic.id`（冗余，用于清晰查询）。`detect_type="doctor"` 标识这是医生维度数据。

- 唯一约束 `(question_id, platform_code, detect_date, detect_round)` 天然区分不同语义（因为semantic.id不同）
- 查询医生数据时用 `semantic_id` 过滤（语义清晰）
- 旧品牌数据 `detect_type="brand"`，`semantic_id=NULL`，不受影响

### 2.3 采集是同步阻塞的

10个语义 × 3个平台 × (API调用~5s + sleep 1s) ≈ **1-3分钟**。前端刷新按钮必须：
- 显示loading状态"数据采集中，可能需要1-3分钟，请稍候..."
- axios超时已经是120s，如果语义多可能不够，第二阶段临时调到180s
- 采集完成后自动刷新数据展示

### 2.4 旧代码全部保留

- `collect_one_question`、`AnswerParser`、品牌监测API、Monitor.tsx 全部保留不动
- 只是前端菜单"数据中心"从 `/monitor` 改指向新的 `/data` 页
- `/monitor` 路由保留，直接访问URL还能打开

### 任务2：新建GEOAEOAnalyzer引擎

**文件改动**：
- 新建 `backend/app/engines/geo_aeo_analyzer.py`

```python
"""GEO/AEO检测解析引擎 — 区分被推荐(GEO)和被引用(AEO)"""
import re
from typing import List, Tuple
from dataclasses import dataclass


@dataclass
class GEOAEOResult:
    """GEO/AEO检测结果"""
    geo_mentioned: bool       # GEO：被推荐进列表
    geo_rank: int             # GEO排名（0=未被推荐）
    aeo_cited: bool           # AEO：被引用为答案
    aeo_confidence: float     # AEO引用置信度 0~1
    raw_answer: str


class GEOAEOAnalyzer:
    """分析AI回答，判断医生是否被GEO推荐和AEO引用"""

    # AEO引用句式模式
    CITATION_PATTERNS = [
        r'(根据|按照|依据).{0,30}(医生|专家|教授|主任).{0,15}(的观点|指出|表示|认为|介绍|建议|提醒|强调)',
        r'(医生|专家|教授|主任).{0,15}(表示|指出|认为|建议|提醒|强调|推荐|介绍)',
        r'(引用|参考|援引).{0,30}(文章|研究|资料|观点)',
        r'据.{0,15}(介绍|了解|报道|分析)',
    ]

    # 治疗方案关键词（AEO辅助判断）
    TREATMENT_KEYWORDS = [
        '治疗方法', '治疗方案', '怎么治', '如何治疗', '治疗建议',
        '预防措施', '注意事项', '用药', '药物', '手术',
        '检查', '诊断', '症状', '原因', '危害',
    ]

    def __init__(self, doctor_name: str, hospital: str, department: str = "",
                 self_intro: str = "", aliases: List[str] = None):
        self.doctor_name = doctor_name or ""
        self.hospital = hospital or ""
        self.department = department or ""
        self.self_intro = self_intro or ""
        self.aliases = aliases or []
        self.patterns = self._build_patterns()

    def _build_patterns(self) -> List[re.Pattern]:
        """构建实体匹配正则模式"""
        patterns = []
        # 医生姓名
        if self.doctor_name and len(self.doctor_name) >= 2:
            patterns.append(re.compile(re.escape(self.doctor_name)))
        # 医院全称
        if self.hospital and len(self.hospital) >= 4:
            patterns.append(re.compile(re.escape(self.hospital)))
        # 医院+医生
        if self.hospital and self.doctor_name:
            patterns.append(re.compile(re.escape(self.hospital + self.doctor_name)))
        # 统一自我介绍
        if self.self_intro and len(self.self_intro) >= 4:
            patterns.append(re.compile(re.escape(self.self_intro)))
        # 别名
        for alias in self.aliases:
            if alias and len(alias) >= 2:
                patterns.append(re.compile(re.escape(alias), re.IGNORECASE))
        return patterns

    def analyze(self, answer: str) -> GEOAEOResult:
        """分析回答，返回GEO/AEO结果"""
        if not answer or not answer.strip():
            return GEOAEOResult(False, 0, False, 0.0, answer)

        # 1. GEO检测：是否提及医生/医院
        geo_mentioned = False
        mention_pos = -1
        for pattern in self.patterns:
            match = pattern.search(answer)
            if match:
                geo_mentioned = True
                mention_pos = match.start()
                break

        if not geo_mentioned:
            return GEOAEOResult(False, 0, False, 0.0, answer)

        # 2. 提取GEO排名
        geo_rank = self._extract_rank(answer, mention_pos)

        # 3. AEO检测：是否被引用为答案
        aeo_cited, aeo_confidence = self._detect_aeo(answer, mention_pos)

        return GEOAEOResult(geo_mentioned, geo_rank, aeo_cited, aeo_confidence, answer)

    def _extract_rank(self, answer: str, mention_pos: int) -> int:
        """提取提及位置的排名（复用AnswerParser的逻辑）"""
        before_text = answer[:mention_pos]
        lines = before_text.split('\n')
        for line in reversed(lines):
            line = line.strip()
            if line:
                m = re.match(r'^(\d+)[\.、\)）]', line)
                if m:
                    rank = int(m.group(1))
                    if 1 <= rank <= 50:
                        return rank
                cn_num = {'一':1,'二':2,'三':3,'四':4,'五':5,'六':6,'七':7,'八':8,'九':9,'十':10}
                m = re.search(r'第([一二三四五六七八九十]+)', line)
                if m and m.group(1) in cn_num:
                    return cn_num[m.group(1)]
        # 按条目计数
        items = re.split(r'\n\s*\d+[\.、\)）]|\n\s*[-*•]\s', answer)
        for i, item in enumerate(items):
            for pattern in self.patterns:
                if pattern.search(item):
                    return i if i > 0 else 1
        return 1  # 提及了但无明确序号，默认排名1

    def _detect_aeo(self, answer: str, mention_pos: int) -> Tuple[bool, float]:
        """检测是否为AEO引用"""
        # 在提及位置前后取上下文
        start = max(0, mention_pos - 200)
        end = min(len(answer), mention_pos + 600)
        context = answer[start:end]

        max_confidence = 0.0

        # 检测引用句式
        for pattern in self.CITATION_PATTERNS:
            if re.search(pattern, context):
                max_confidence = max(max_confidence, 0.8)
                break

        # 检测治疗方案内容（辅助提升置信度）
        has_treatment = any(kw in context for kw in self.TREATMENT_KEYWORDS)
        if has_treatment:
            max_confidence = max(max_confidence, 0.5)

        # 如果回答整体较短且直接给出方案，AEO置信度中等
        if len(answer) < 500 and has_treatment and geo_mentioned:
            max_confidence = max(max_confidence, 0.6)

        return (max_confidence >= 0.5, round(max_confidence, 2))
```

> 注意：`_detect_aeo` 里引用了 `geo_mentioned` 变量，但这个变量在 `analyze` 方法里，不在 `_detect_aeo` 的作用域。需要把它作为参数传进去，或者在 `_detect_aeo` 里重新判断。修正：`_detect_aeo(self, answer, mention_pos, geo_mentioned: bool)`。

```python
        # 批量入库（先按semantic_id删旧记录，不能按question_id删！）

                    MonitorRecord.detect_date == today,
                    MonitorRecord.detect_round == detect_round
                ).delete(synchronize_session=False)
                self.db.commit()

                self.db.add_all(records)
                self.db.commit()
                logger.info(f"语义 [{semantic.id}] GEO/AEO采集完成，入库 {len(records)} 条记录")
            except Exception as e:
                self.db.rollback()
                logger.error(f"GEO/AEO入库失败: {e}")

        return records

    def collect_all_semantics(self, user_id: int, detect_round: int = 99) -> Dict:
        """采集指定用户所有启用语义的GEO/AEO数据"""
        from app.models.semantic import Semantic
        from app.models.doctor import DoctorProfile

        profile = self.db.query(DoctorProfile).filter(DoctorProfile.user_id == user_id).first()
        if not profile:
            return {"total": 0, "success": 0, "error": "未找到医生Profile"}

        semantics = self.db.query(Semantic).filter(
            Semantic.user_id == user_id,
            Semantic.is_active == True
        ).all()

        total = len(semantics)
        success_count = 0
        all_records = []

        logger.info(f"开始用户 [{user_id}] 全量GEO/AEO采集，共 {total} 个语义")

        for i, semantic in enumerate(semantics):
            try:
                records = self.collect_one_semantic(semantic, profile, detect_round)
                all_records.extend(records)
                success_count += 1
            except Exception as e:
                logger.error(f"采集语义失败 [{semantic.question}]: {e}")
            if i < total - 1:
                time.sleep(2)

        # 更新semantic表的geo_rate/aeo_rate缓存
        self._update_semantic_rates(user_id)

        logger.info(f"用户 [{user_id}] GEO/AEO采集完成: {success_count}/{total}")
        return {
            "total": total,
            "success": success_count,
            "records_count": len(all_records),
            "platforms": adapter_factory.get_enabled_platforms(),
        }

    def _update_semantic_rates(self, user_id: int):
        """更新semantic表的geo_rate/aeo_rate缓存字段"""
        from app.models.semantic import Semantic
        from sqlalchemy import func

        semantics = self.db.query(Semantic).filter(Semantic.user_id == user_id).all()
        platforms = adapter_factory.get_enabled_platforms()
        total_platforms = len(platforms) if platforms else 1

        for s in semantics:
            records = self.db.query(MonitorRecord).filter(
                MonitorRecord.semantic_id == s.id,
                MonitorRecord.detect_type == "doctor"
            ).order_by(MonitorRecord.detect_time.desc()).limit(total_platforms).all()

            if records:
                geo_count = sum(1 for r in records if r.mentioned)
                aeo_count = sum(1 for r in records if r.cite_count > 0)
                s.geo_rate = round(geo_count / len(records) * 100, 1)
                s.aeo_rate = round(aeo_count / len(records) * 100, 1)
                s.article_count = self.db.query(MonitorRecord).filter(
                    MonitorRecord.semantic_id == s.id
                ).count()  # 这个字段实际应该存文章数，这里先不改动

        self.db.commit()
```

> 注意：
> 1. `question_id=semantic.id` 是关键，不能填0
> 2. 删旧记录按 `semantic_id` 删，不是 `question_id`
> 3. `_update_semantic_rates` 里 `article_count` 不应该在这里更新（那是文章数，不是监测记录数），把那行去掉或改成不更新article_count
> 4. import放在方法内部是为了避免循环引用

```tsx
      { name: 'GEO推荐率', type: 'line', smooth: true, data: overview.trend_7days.map((d: any) => d.geo_rate), itemStyle: { color: '#0EA5E9' }, areaStyle: { color: 'rgba(14,165,233,0.1)' } },

    ]
  } : {}

  const columns = [
    { title: '语义问题', dataIndex: 'question', key: 'question', ellipsis: true },
    { title: 'GEO推荐率', dataIndex: 'geo_rate', key: 'geo_rate', width: 110,

    { title: '最佳GEO排名', dataIndex: 'best_rank', key: 'best_rank', width: 100,
      render: (r: number) => r > 0 ? <Tag color="green">第{r}名</Tag> : <Tag color="default">未推荐</Tag> },
    { title: '状态', dataIndex: 'is_active', key: 'is_active', width: 80,
      render: (v: boolean) => v ? <Tag color="blue">监测中</Tag> : <Tag>已停用</Tag> },
    { title: '操作', key: 'action', width: 100,
      render: (_: any, record: any) => (
        <Button type="link" size="small" icon={<EyeOutlined />} onClick={() => handleViewDetail(record.semantic_id)}>详情</Button>

  ]

  return (

      </div>

          <Card size="small"><Statistic title="GEO推荐率" value={overview?.overall_geo_rate ?? 0} suffix="%" valueStyle={{ color: '#0EA5E9' }} /></Card>
        </Col>
        <Col xs={12} sm={6}>
          <Card size="small"><Statistic title="AEO引用率" value={overview?.overall_aeo_rate ?? 0} suffix="%" valueStyle={{ color: '#8B5CF6' }} /></Card>
        </Col>
        <Col xs={12} sm={6}>
          <Card size="small"><Statistic title="监测语义数" value={overview?.active_semantics ?? 0} suffix={`/ ${overview?.total_semantics ?? 0}`} /></Card>
        </Col>
        <Col xs={12} sm={6}>
          <Card size="small"><Statistic title="最后刷新" value={overview?.last_refresh || '从未'} valueStyle={{ fontSize: 16 }} /></Card>
        </Col>
      </Row>

      {/* 趋势图 */}
      <Card title="近7天 GEO/AEO 趋势" style={{ marginBottom: 16 }}>
        {overview?.trend_7days?.length ? (
          <ReactECharts option={trendOption} style={{ height: 280 }} />
        ) : (
          <Empty description="暂无趋势数据，点击右上角手动刷新" style={{ height: 200, padding: 40 }} />
        )}
      </Card>

      {/* 语义数据表 */}
      <Card title="各语义 GEO/AEO 表现">
        <Table
          dataSource={overview?.semantic_stats || []}
          columns={columns}
          rowKey="semantic_id"
          loading={loading}
          pagination={{ pageSize: 10 }}
          locale={{ emptyText: '暂无数据，请先完善Profile并刷新' }}
        />
      </Card>

      {/* 详情抽屉 */}
      <Drawer title="语义详情" placement="right" width={600} open={drawerVisible} onClose={() => setDrawerVisible(false)}>
        <Spin spinning={detailLoading}>
          {detail && (
            <div>
              <Descriptions column={1} size="small" style={{ marginBottom: 16 }}>
                <Descriptions.Item label="语义问题">{detail.question}</Descriptions.Item>
                <Descriptions.Item label="最后刷新">{detail.last_refresh || '从未'}</Descriptions.Item>
              </Descriptions>

              <h4 style={{ marginBottom: 12 }}>各平台检测结果</h4>
              {detail.platform_details?.length ? detail.platform_details.map((p: any) => (
                <Card key={p.platform_code} size="small" style={{ marginBottom: 8 }}
                  title={
                    <span>
                      {PLATFORM_NAMES[p.platform_code] || p.platform_code}
                      <Tag color={p.geo_mentioned ? 'green' : 'default'} style={{ marginLeft: 8 }}>
                        GEO: {p.geo_mentioned ? `第${p.geo_rank}名` : '未推荐'}
                      </Tag>
                      <Tag color={p.aeo_cited ? 'purple' : 'default'}>
                        AEO: {p.aeo_cited ? `已引用(${p.aeo_confidence})` : '未引用'}
                      </Tag>
                    </span>
                  }>
                  <div style={{ background: '#F8FAFC', padding: 12, borderRadius: 8, fontSize: 13, lineHeight: 1.8, maxHeight: 300, overflow: 'auto', whiteSpace: 'pre-wrap' }}>
                    {p.raw_answer || '暂无回答'}
                  </div>
                </Card>
              )) : <Empty description="暂无平台数据" />}
            </div>
          )}
        </Spin>
      </Drawer>
    </div>
  )
}

export default DataCenter
```
