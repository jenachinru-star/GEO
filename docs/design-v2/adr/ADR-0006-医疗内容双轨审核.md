# ADR-0006：医疗内容双轨审核

状态：Accepted  
日期：2026-09-14

## 问题

健康科普与带预约、机构、价格、疗效的推广内容风险不同。现有模板可能生成无证据资历、占位价格和直接就诊引导。

## 选择

内容分 education 与 promotion；使用 draft → fact_check → medical_review → compliance_review → approved → published 状态机。高风险内容禁止自动批准和自动发布。

## 约束

关键 Claim 必须绑定证据；占位符、绝对化承诺、虚构病例和患者可识别信息直接阻止发布。内容修改使旧批准失效。

## 现实折中

小团队可由同一人承担多个审核角色，但系统记录角色和决定；正式商业推广上线前由专业合规人员复核规则。

## 重新评估条件

业务地区、内容平台、医疗服务类型或监管要求变化时，新增规则版本和 ADR，不改写历史审核记录。
