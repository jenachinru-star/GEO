# ADR-0004：AEO 来源引用定义

状态：Accepted  
日期：2026-09-14

## 问题

当前系统把医生附近的治疗关键词、普通提及和推荐混入 AEO，前端甚至表述为“唯一答案”，没有可验证来源。

## 选择

AEO 成功必须存在可验证 http/https 来源，且来源支持与目标医生相关的事实或回答。没有 URL/结构化 source 时，只能计算提及或推荐。

## 独立指标

请求成功率、提及率、推荐率、明确排名、来源引用率、自有来源引用率、第三方来源引用率、唯一推荐和 Share of Voice 分开计算。

## 约束

- 医院名不能独立命中医生；
- 无明确排序时 rank=null；
- 负面提及不算推荐；
- Provider 错误不进入业务分母；
- “唯一”需证明没有其他同类候选。

## 重新评估条件

行业对 AEO 形成新的公认标准时，可新增指标映射，但历史 methodology_version 不改写。
