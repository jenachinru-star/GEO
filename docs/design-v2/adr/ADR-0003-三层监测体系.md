# ADR-0003：三层监测体系

状态：Accepted  
日期：2026-09-14

## 问题

普通模型 API、联网搜索回答和消费者网页/App 的结果来源、实时性和可复现性不同，不能混为一个可见度。

## 选择

采用三层体系：chat 模型认知基准、grounded_search 联网来源监测、consumer_audit 消费者前台抽检。

## 展示规则

三层结果分别存储、分别统计。Provider 名称不代表消费者产品。趋势必须限定 mode、模型、问题版本、地区和采样方法。

## 理由

兼顾可重复自动监测与真实用户体验，同时避免不稳定网页自动化成为核心依赖。

## 当前 GLM 结论

普通 Chat 已完成最小调用验证；当前代理端点的联网搜索和来源能力仍待探测，未验证前不能进入 grounded_search。

## 重新评估条件

某 Provider 提供经验证、稳定且明确等价于消费者产品的官方接口时，可以提升其证据等级，但仍保留 mode 标识。
