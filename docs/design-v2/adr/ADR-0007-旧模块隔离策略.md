# ADR-0007：旧模块先隔离后归档

状态：Accepted  
日期：2026-09-14

## 问题

旧全局表缺少所有权，立即删除会丢失数据；继续对普通用户开放又会泄漏和扩大技术债。

## 选择

按顺序处理：停止扩建 → 普通用户隐藏导航 → 后端关闭写入/限制权限 → 管理员只读 → 识别所有权 → 可验证迁移 → 不可识别归档 → 最后删除旧结构。

## 适用模块

Question/MonitorRecord 品牌链、旧 Content、Knowledge/RAG、Competitor、Platform DB 配置和 Go CLI。

## 约束

隐藏菜单不是隔离；不能把无法识别的数据平均分给现有用户；旧表删除必须独立迁移和备份签字。

## 重新评估条件

如果某旧模块被证明对医生闭环有直接价值，必须先补 Workspace、权限、指标和测试，再以新模块身份保留。
